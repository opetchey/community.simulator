# Linear model with infinite value check

Linear model with infinite value check

## Usage

``` r
lm_with_inf_check(formula, data)
```

## Arguments

- formula:

  Linear regression model y ~ x

- data:

  Data frame containing the data

## Value

A linear model object with slope replaced with NA if the data contains
any Inf values
