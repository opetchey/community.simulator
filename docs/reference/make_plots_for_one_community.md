# Make graphs showing variance results from one case

Make graphs showing variance results from one case

## Usage

``` r
make_plots_for_one_community(experiment_folder, case_id_oi)
```

## Arguments

- experiment_folder:

  The folder where the experiment is stored

- case_id_oi:

  The case id of the case to be plotted

## Value

List of graphs.
