# Get the stability of each case (community). Calculated CV of total biomass temporal variation. Also returns mean total biomass and standard deviation of total biomass

Get the stability of each case (community). Calculated CV of total
biomass temporal variation. Also returns mean total biomass and standard
deviation of total biomass

## Usage

``` r
get_community_popstab(dynamics)
```

## Arguments

- dynamics:

  Connection to database containing dynamics data

## Value

A dataset containing the stability of each case (community). Calculated
CV of total biomass temporal variation. Also returns mean total biomass
and standard deviation of total biomass
