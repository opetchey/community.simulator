# Run the simulation explorer Shiny app

Launches a small exploratory Shiny app for building one community,
inspecting its structure, and simulating its dynamics on demand.

## Usage

``` r
run_simulation_explorer()
```

## Value

The return value from
[`shiny::runApp()`](https://rdrr.io/pkg/shiny/man/runApp.html).

## Examples

``` r
if (FALSE) { # \dontrun{
run_simulation_explorer()
} # }
```
