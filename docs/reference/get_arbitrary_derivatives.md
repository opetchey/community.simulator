# Get derivatives at arbitrary temperatures

Get derivatives at arbitrary temperatures

## Usage

``` r
get_arbitrary_derivatives(
  experiment_folder,
  experiment_design_filename,
  overwrite = FALSE,
  verbose = TRUE
)
```

## Arguments

- experiment_folder:

  The folder where the experiment is stored

- experiment_design_filename:

  The file with the experiment design

- overwrite:

  Logical. If `TRUE`, overwrite an existing arbitrary-derivatives
  database.

- verbose:

  Logical. If `TRUE`, print progress and output messages.

## Value

Data base with the derivatives at arbitrary temperatures
