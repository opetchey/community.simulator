# Get the sum of the communities derivatives at arbitrary temperatures and at actual (temp = temporal) temperatures

Get the sum of the communities derivatives at arbitrary temperatures and
at actual (temp = temporal) temperatures

## Usage

``` r
get_community_sum_derivatives(arb_derivs, temp_derivs, delta_igr)
```

## Arguments

- arb_derivs:

  Connection to database containing arbitrary derivatives

- temp_derivs:

  Connection to database containing temporal (actual) derivatives

- delta_igr:

  Connection to database containing delta IGR

## Value

A dataset containing the sum of the derivatives at arbitrary and actual
temperatures
