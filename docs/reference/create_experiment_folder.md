# Create folder for experiment

Create folder for experiment

## Usage

``` r
create_experiment_folder(
  experiment_folder_location,
  experiment_name,
  verbose = TRUE
)
```

## Arguments

- experiment_folder_location:

  Location of experiment folder

- experiment_name:

  Name of experiment

- verbose:

  Logical. If `TRUE`, print messages about folder creation.

## Value

A message indicating if the folder was created or if it already exists,
and the location of the folder
